Set up the repository

Download and review the setup script, then run it as root. It verifies the keyring package checksum, configures the scoped signing key and refreshes APT.

curl --fail --location --output install.sh \
  https://amogosbuild.github.io/amogos-debian/install.sh
less install.sh
sudo sh install.sh

Then install an app, for example:

sudo apt install amogos-notes amogos-music amogos-store

The repository adds AmogOS packages alongside your Debian repositories. The installer is available as amogos-installer for live installation media.

System update migrations

The 2.1 update repairs Debian package support, upgrades the App Store and removes live installers from installed systems. Systems already on 2.1 or newer report that they are up to date. When a newer package version is installed during an OS update, its new script runs automatically. Successful versions are recorded so reinstalls do not repeat them; failed migrations remain pending.
